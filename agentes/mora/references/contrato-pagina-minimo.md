# Contrato de página mínimo

Se carga **solo si el proyecto no declara `mora.doc_standard`**. Si existe, ese estándar manda.

```text
Header → Overview → Usage → Preview/Examples → Anatomy → variantes/estados aplicables
→ Behavior → Responsive → Accessibility → API real → Implementation → QA/Lifecycle
```

Es un **orden relativo**, no una obligación de producir secciones vacías (las reglas que aplican siempre están en el §6 del manual).
