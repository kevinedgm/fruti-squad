# Caso 05: diálogo de confirmación destructiva

## Petición
`Diseña el diálogo para cancelar una cuenta pendiente; debe decir cuántas muestras se cancelan`

## Ruta esperada
Kiwi → Lima → Coco → Lima gate → Mora.

## Debe
- [ ] El título dice la acción y su consecuencia; el botón de confirmar repite el verbo ("Cancelar cuenta").
- [ ] Foco inicial en la acción segura; Escape cierra; el foco vuelve al disparador.
- [ ] La acción destructiva no comparte tratamiento con la principal habitual.

## No debe
- [ ] Botones "Sí / No" sin verbo.
- [ ] Diálogo sin rol ni nombre accesible.
