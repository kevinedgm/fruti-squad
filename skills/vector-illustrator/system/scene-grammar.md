# Scene Grammar
Fórmula: sujeto + acción + objeto/contexto + señal visual opcional. Antes del render definir message, moment, focal_action, cast, props, focal_point, reading_direction, camera, depth, palette y accent_target. Relaciones: mirar, manipular, colaborar, reaccionar, señalar, presentar, entrar/salir del encuadre y asomarse. Mantener 2D y 2–3 capas.
