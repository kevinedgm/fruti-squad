# Lenguaje visual
Contorno negro dominante, curvas orgánicas, cabeza ligeramente alargada, nariz lineal angular, ojos simples, oreja visible cuando corresponda, cabello como masa sólida o grandes mechones, manos expresivas, superficies claras, 1–3 acentos y marcas cinéticas breves.

Debe sentirse amable, humana, espontánea, moderna y ligeramente humorística. Evitar clip-art corporativo genérico, 3D, fotorealismo, geometría CAD, iconos flotantes sin función narrativa y copia de referencias.
