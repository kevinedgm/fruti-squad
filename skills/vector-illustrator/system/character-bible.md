# Character Bible
Crear una población coherente, no un único personaje repetido.

Dimensiones: presentation masculine|feminine|neutral; age_visual young-adult|adult|older-adult; build slim|average|broad; hair short-wave|crop|curls|bob|long|bun|ponytail|custom; face_variant a|b|c|d; outfit casual|professional|technical|medical|custom.

Rostro: cabeza orgánica, nariz angular de pocas líneas, ojos simples, boca corta, oreja simplificada y cuello claramente separado. Cabello puede usar masas negras sólidas. Manos 1.15–1.35x cuando son comunicativas. Mantener stroke, gramática facial, proporciones y comportamiento del color entre personajes.
