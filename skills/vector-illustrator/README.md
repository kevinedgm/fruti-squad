# Vector Illustrator Skill
Skill modular de Fruti Squad para crear familias consistentes de ilustraciones vector-ready.

## Entrada recomendada
Usar brief estructurado: variant, subject, action, emotion, characters, background y accent.

## Prueba de aceptación
Generar al menos 20 activos en varias variantes. Deben reconocerse como la misma familia sin depender del logotipo ni de una paleta fija.
