# Anatomía
Cabeza y torso deben leerse como masas separadas. El cuello no se fusiona con nariz, mandíbula, brazo o fondo. Hombros indican el origen de los brazos. Codos y muñecas deben ser inferibles. Manos importantes requieren silueta clara. Evitar extremidades duplicadas, dedos fusionados accidentalmente y articulaciones imposibles. Si una pose necesita explicación para entenderse, rediseñarla.
