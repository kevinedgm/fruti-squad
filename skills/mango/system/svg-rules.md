# SVG
Usar `viewBox`; preferir `path`, `circle`, `ellipse`, `rect`, `line`, `polyline`, `polygon` y `g`. No raster/base64. Evitar texto salvo solicitud explícita. Agrupar `character`, `props`, `accents`, `motion`. Mantener paths editables. Permitir `currentColor` o variables CSS si el consumidor lo pide.
