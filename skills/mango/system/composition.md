# Composición
1. Bounding box y zona segura.
2. Sujeto focal.
3. Línea de acción y dirección de lectura.
4. Alinear mirada, cabeza, torso y manos con la acción.
5. Props funcionales.
6. Acentos de énfasis/movimiento.
7. Espacio negativo.

Preferir asimetría controlada. Para UI dejar aire. En edge characters, el recorte coincide con el borde real. Evitar tangencias accidentales.
