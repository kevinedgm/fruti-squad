# 🥭 Mango · Vector Illustrator Skill
Skill modular para crear una familia consistente de ilustraciones vector-ready.

## Prueba de aceptación
Generar al menos 20 activos distintos en varias variantes. Deben reconocerse como la misma familia sin depender del logotipo ni de una paleta fija.

## Instalación
Con Fruti Squad: `npx github:kevinedgm/fruti-squad install --target claude --only kiwi,lima,coco,mora,uva,mango` (se instala como la skill `mango`). Fuera de Fruti Squad: copiar esta carpeta al directorio de skills del agente y adaptar solo el front matter si ese runtime usa otro formato.
