# Estado

Aviso de estado: icono + texto sobre el fondo suave del estado.

- Éxito: `success-soft` con `on-success-soft` y palomita. Error: `danger-soft` con `on-danger-soft` y cruz.
- Hitos de marca (perfil destacado, verificado): `cadmio-soft` con `text` y la u del símbolo.
- Nunca solo color; el texto dice qué pasó. Radio `radius-md`, padding 8 por 12.
- El consumidor provee: el texto y, si procede, la acción siguiente.
