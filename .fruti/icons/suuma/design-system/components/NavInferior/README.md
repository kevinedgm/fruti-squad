# NavInferior

Navegación inferior para móvil: cuatro destinos; el activo en `text` con una barra de cadmio debajo.

- Fondo `surface`, borde superior `border`, 44 px mínimo por destino, icono de 22 px y etiqueta de 12 px a 500.
- Activo: texto en `text` y barra de 18×3 px en `cadmio`; inactivo: `text-muted`. Nunca solo color.
- Destinos: Hoy, Buscar, Agenda, Perfil.
- El consumidor provee: rutas y destino activo.
