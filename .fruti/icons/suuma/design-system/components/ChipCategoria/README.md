# ChipCategoria

Chip de categoría: icono + texto en un borde fino, nunca solo color.

- Fondo `surface`, borde `border`, texto `text`. Seleccionado: borde `text` sobre `cadmio-soft`.
- Icono de la categoría a 16 px, o la u de la marca mientras no exista.
- Altura 32 px, radio `radius-sm`, 13 px a 600.
- El consumidor provee: nombre de la categoría y, si filtra, `aria-pressed`.
