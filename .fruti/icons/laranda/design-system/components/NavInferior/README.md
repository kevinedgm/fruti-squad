# NavInferior

Navegación inferior para móvil: cuatro destinos, el activo en `brand`.

- Fondo `surface`, borde superior `border`, 44 px mínimo por destino, icono de 22 px y etiqueta de 12 px a 500.
- Activo: icono y texto en `brand`; inactivo: `text-muted` (7.7:1). Nunca solo el color: el icono activo también se rellena.
- Destinos: Hoy, Agenda, Perfil, Folios. Reservar no vive aquí: vive en el perfil público.
- El consumidor provee: las rutas y el destino activo.
