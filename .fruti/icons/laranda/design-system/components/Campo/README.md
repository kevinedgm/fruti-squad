# Campo

Campo de texto con etiqueta arriba, ayuda abajo y error en `danger`.

- 44 px de alto, borde `border-control` (3.4:1), radio `radius-md` (8 px), fondo `surface`.
- Foco: borde `brand` y anillo `focus`. Error: borde `danger` y mensaje en `danger` que dice cómo corregir.
- Etiqueta `label` 14/20 a 500; ayuda `caption` en `text-muted`.
- El consumidor provee: etiqueta, valor, mensaje de ayuda o error, y el `id` que une etiqueta y campo.
