# Estado

Aviso de estado: icono + texto sobre el fondo suave del estado.

- Éxito: `success-soft` con `on-success-soft` e icono de palomita. Error: `danger-soft` con `on-danger-soft` e icono de cruz.
- Hitos del negocio (perfil publicado, primera reseña, verificado): `brand-soft` con `brand` y la silueta de la flor; en la primera aparición, la flor se abre con `bloom`.
- Nunca solo color; el texto dice qué pasó. Radio `radius-md`, padding 8 por 12.
- El consumidor provee: el texto del estado y, si procede, la acción siguiente.
