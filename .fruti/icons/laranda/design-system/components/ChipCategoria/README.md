# ChipCategoria

Chip de categoría del profesional: icono + texto en un borde fino, nunca solo color.

- Fondo `surface`, borde `border`, texto `text`; seleccionado: borde y texto `brand` sobre `brand-soft`; variante de acento: borde y texto `accent`.
- Icono: la silueta de la flor a 16 px, o el icono de la categoría cuando exista.
- Altura 32 px, radio `radius-sm` (10 px), 13 px a 600.
- El consumidor provee: nombre de la categoría y, si el chip filtra, `aria-pressed`.
