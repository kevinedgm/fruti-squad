# ChipCategoria

Chip de categoría del profesional: color + icono + texto, nunca solo color.

- Fondo `brand-soft`, texto e icono `brand`; seleccionado: `brand` con `on-brand`; variante de acento: `accent-soft` con texto `text`.
- Icono: la silueta de la flor a 16 px, o el icono de la categoría cuando exista.
- Altura 32 px, radio `radius-pill`, `label` 14/20 a 600.
- El consumidor provee: nombre de la categoría y, si el chip filtra, `aria-pressed`.
