# FlujoResena

Flujo de reseña en tres pasos, 20 segundos, después de una cita con folio.

- Paso 1: «¿Volverías con [nombre]?», sí o no, un toque. Paso 2: etiquetas de qué salió bien (seis fijas por categoría). Paso 3: texto opcional.
- La calificación se deriva: sí con tres o más etiquetas = 5; sí = 4; no con etiquetas = 2; no = 1. Quien quiera afinar toca las flores (`Calificacion`).
- Se ofrece una vez, al cerrar el folio; se puede posponer («Ahora no») y vuelve a ofrecerse una sola vez más.
- El consumidor provee: nombre del profesional, las etiquetas de su categoría y el `onSubmit` con volvería, etiquetas, texto y calificación.
