# Resena

Reseña publicada: calificación en flores, sello «con folio», texto, etiquetas y quién la escribió.

- Solo quien tuvo folio puede reseñar; el sello lo dice en `success-soft` con la silueta de la flor.
- La línea de meta dice si el cliente volvió a reservar: es el dato que más pesa.
- El profesional responde una vez, en público, en una tarjeta con borde `brand` y `overline` en `brand`.
- Las reseñas no se borran: se reportan y pasan a «en revisión».
- El consumidor provee: calificación, texto, etiquetas, autor, fecha, si volvió y la respuesta.
