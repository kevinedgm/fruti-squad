# Nexa Squad · ronda 1 · símbolos en tinta

Usuario (2026-11-08): «así como hicimos la guía de marca de Fruti Squad y el kit de marketplace, crea la identidad de marca para kevinedgm/nexa-squad y sus productos».
Fuente de productos: `squad.json` y README de `kevinedgm/nexa-squad` (Orka, Inqa, Arko, Fluxa, Kompa, Kura, Forja, Vera + el squad).
Mismo método que Fruti Squad (`../../fruti-squad-2/`): primero símbolos en tinta, después color, tipografía, paquete final, guía y kit.

- **A · Retícula:** rejilla 3 × 3; contorno = lo que ya existe, lleno = lo que decide el agente. Se separa de Fruti (trazo).
- **B · Hilo:** un trazo de 3.5 con nodos, como Fruti: marca hermana. Arko = arco, Kompa = compás, Fluxa = flujo, Vera = palomita.
- Riesgos anotados: A, Orka y Kompa ligeros a 16 px; B, Inqa y Vera comparten la palomita y Kompa se lee como «A».

`python3 gen.py` → `simbolos.html`. Pendiente: elección del usuario.
