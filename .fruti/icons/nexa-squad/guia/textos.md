# Nexa Squad · textos de marketplace

Fuente: squad.json y README de kevinedgm/nexa-squad. Lema corto + descripción, en español e inglés.

## Nexa Squad · Composición de módulos

**ES** · Ocho agentes que diseñan y construyen módulos completos acomodando bien los componentes que ya tienes.

Nexa Squad cubre un módulo de punta a punta: requisitos, servidor, flujo, composición, componentes, construcción y revisión. Cada decisión tiene un solo dueño y cita su fuente (WCAG, GOV.UK, Material, Nielsen, Baymard). Empiezas con /orka y lo pides con tus palabras. Funciona en Claude Code, Codex y Kiro, y convive con Fruti Squad.

**EN** · Eight agents that design and build complete modules by arranging the components you already have.

Nexa Squad covers a module end to end: requirements, server, flow, composition, components, build and review. Every decision has a single owner and cites its source (WCAG, GOV.UK, Material, Nielsen, Baymard). Start with /orka and ask in your own words. Works with Claude Code, Codex and Kiro, alongside Fruti Squad.

## Orka · Conductor

**ES** · Dirige el squad: quién trabaja ahora y qué se aprueba solo.

Reconoce el escenario, lanza un rol a la vez, resuelve lo que se puede inferir, aprueba documentos intermedios y solo te interrumpe por reglas de negocio o por algo que no se puede deshacer.

**EN** · Runs the squad: who works now and what gets approved on its own.

Recognizes the scenario, runs one role at a time, resolves what can be inferred, approves intermediate documents and only interrupts you for business rules or anything irreversible.

## Inqa · Product Analyst

**ES** · Qué debe hacer la funcionalidad, para quién y cómo se comprueba.

Separa hechos, supuestos y preguntas antes de diseñar o programar, y entrega requisitos con criterios Dado/Cuando/Entonces.

**EN** · What the feature must do, for whom, and how to verify it.

Separates facts, assumptions and questions before any design or code, and delivers requirements with Given/When/Then criteria.

## Arko · Systems Architect

**ES** · Cómo se construye por detrás: datos, API y permisos.

Lee el stack real y decide datos, contratos de API y permisos validados en el servidor; para cada decisión importante, dos opciones con costo y riesgo.

**EN** · How it is built underneath: data, APIs and permissions.

Reads the real stack and decides data, API contracts and server-side permissions; for each key decision, two options with cost and risk.

## Fluxa · Flow Designer

**ES** · Qué pantallas hay, qué contienen y en qué orden.

Hace el inventario de vistas en el orden real de la tarea y da a cada vista de gestión su estructura: cabecera, herramientas, datos y pie.

**EN** · Which screens exist, what they contain and in what order.

Inventories the views in the real order of the task and gives each management view its structure: header, toolbar, data and footer.

## Kompa · Layout Composer

**ES** · Cómo se acomoda cada sección: qué crece, qué cede y qué nunca se mueve.

Decide jerarquía, agrupación y espaciados con los tokens que ya existen, y revisa cada vista en escritorio, tableta y teléfono.

**EN** · How each section is laid out: what grows, what yields and what never moves.

Decides hierarchy, grouping and spacing with existing tokens, and checks every view on desktop, tablet and phone.

## Kura · Component Curator

**ES** · Reutilizar antes que crear.

Para cada hueco busca primero lo que existe y cuenta cuántas veces aparece: reutilizar, variante, componente nuevo o local. Lo que falta se lo pide a Fruti Squad.

**EN** · Reuse before you create.

For every gap it first searches what exists and counts how often it appears: reuse, variant, new component or local. Whatever is missing is requested from Fruti Squad.

## Forja · Build Engineer

**ES** · Escribe el código que cumple lo aprobado, fase por fase.

Construye primero datos, API y permisos, luego las vistas con los componentes y tokens del catálogo, y prueba cada criterio que pueda probar.

**EN** · Writes the code that meets what was approved, phase by phase.

Builds data, API and permissions first, then the views with catalog components and tokens, and tests every criterion it can.

## Vera · QA Auditor

**ES** · Si pasa, o a quién regresa cada hallazgo.

Audita lo construido contra los documentos aprobados, dice cómo verificó cada punto y regresa cada hallazgo al rol dueño de la decisión que falló.

**EN** · Pass, or who each finding goes back to.

Audits the build against the approved documents, states how each point was verified and returns every finding to the role that owns the failed decision.
