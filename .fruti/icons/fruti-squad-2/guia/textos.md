# Fruti Squad · textos de marketplace

Fuente de las responsabilidades: README del paquete. Lema corto + descripción, en español e inglés.

## Fruti Squad · Workflow Pack

**ES** — Agentes especialistas que diseñan, gobiernan, implementan, auditan y documentan interfaces.

Un sistema multiagente para interfaces de usuario: cada agente hace una sola clase de trabajo y entrega evidencia al siguiente. Incluye a Kiwi (estructura), Lima (gobernanza), Coco (auditoría visual), Bruno (implementación) y Mora (documentación), con contratos, estado y traspasos en un runtime local.

**EN** — Specialist agents that design, govern, build, audit and document user interfaces.

A multi-agent system for user interfaces: each agent does one kind of work and hands verified evidence to the next. Includes Kiwi (structure), Lima (governance), Coco (visual audit), Bruno (implementation) and Mora (documentation), with contracts, state and handoffs in a local runtime.

## Kiwi · UX Architect

**ES** — Define la estructura antes que la apariencia.

Brief funcional, user flow, arquitectura de pantalla, jerarquía, estados y comportamiento en compact, medium y expanded. Entrega wireframes F0–F2 y contratos geométricos; no decide color, tipografía ni implementación.

**EN** — Structure before appearance.

Functional brief, user flow, screen architecture, hierarchy, required states and behavior across compact, medium and expanded. Delivers F0–F2 wireframes and geometry contracts; it does not decide color, typography or implementation.

## Lima · Design System Governance

**ES** — Gobierna tu design system: una fuente, muchas piezas coherentes.

Clasifica cada pieza (reutilizar, extender, nueva o local), define contratos, tokens y registro, administra el ciclo de vida y aplica quality gates de promoción y deprecación.

**EN** — Govern your design system: one source, many consistent pieces.

Classifies every piece (reuse, extend, new or local), defines contracts, tokens and registry, manages lifecycle and applies promotion and deprecation quality gates.

## Coco · UI Audit

**ES** — Construye la capa visual y la audita contra el contrato.

Compone la versión visual con el sistema real y después audita cumplimiento, consistencia, accesibilidad observable, overflow, densidad, uso de tokens y desviaciones del contrato, con evidencia.

**EN** — Builds the visual layer and audits it against the contract.

Composes the visual version with the real system, then audits compliance, consistency, observable accessibility, overflow, density, token usage and contract deviations, with evidence.

## Bruno · Frontend Implementation Engineer

**ES** — Convierte la pieza aprobada en comportamiento frontend real.

Props, eventos, slots, estados controlados, interacción, teclado, foco y ARIA funcional, sobre la estructura, el contrato y el CSS ya aprobados, sin reinterpretarlos.

**EN** — Turns the approved piece into real frontend behavior.

Props, events, slots, controlled state, interaction, keyboard, focus and functional ARIA, built on the approved structure, contract and CSS without reinterpreting them.

## Mora · Documentation & Knowledge Engineer

**ES** — Documenta solo lo que existe y fue verificado.

Design Hub, páginas de componentes, registro, navegación, cobertura, deprecaciones y ejemplos, siempre sincronizados con el código y con la evidencia de implementación.

**EN** — Documents only what exists and was verified.

Design Hub, component pages, registry, navigation, coverage, deprecations and examples, always in sync with the code and implementation evidence.
