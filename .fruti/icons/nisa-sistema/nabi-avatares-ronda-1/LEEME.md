# Nabi · avatares · ronda 1

Petición: el sistema no admite foto de perfil; el usuario solo puede cambiar el fondo del avatar y la figura queda fija.
Interpretación (supuesto): la figura la asigna el sistema y no se edita; el usuario elige el fondo entre diez colores de Nisa Nabani (azul real, azul medio, cian, verde, verde claro, pera, naranja, café, morado, niebla).
Reglas: la figura se pinta en blanco o azul según el contraste con el fondo (mínimo 4.6:1 en los diez); la muestra pera solo aparece si contrasta ≥ 2.2:1 con el fondo.

- A · Iniciales en pocillos: dos iniciales en matriz de 3×5 pocillos (sin puntos vacíos); la última pocilla de la segunda letra es la muestra.
- B · Placa única: patrón 4×4 simétrico derivado del nombre (SHA-1), con una muestra pera.
- C · Figura fija: cabeza y hombros de pocillos, igual para todos.

`gen.py <scratchpad>` genera `banco.html` y un SVG por concepto y usuario de ejemplo (nombres ficticios).
