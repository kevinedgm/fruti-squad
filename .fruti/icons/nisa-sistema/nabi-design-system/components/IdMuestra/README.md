# IdMuestra

Identificador de muestra, lote o certificado: etiqueta en versalitas (Poppins) y folio en Google Sans Code, copiable.

- Etiqueta en `overline`; folio en `folio` (Google Sans Code 13/18, cero con barra, tracking 0.02em) para que 0 y O, 1 e I nunca se confundan.
- Botón de copiar en las vistas donde el folio se pega en otro sistema.
- El consumidor provee: tipo, folio y si es copiable. El formato del folio lo define el laboratorio; los de ejemplo son ilustrativos.
