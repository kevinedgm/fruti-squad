# EstadoMuestra

Estado de una muestra o lote: icono + texto sobre el fondo suave del estado.

- Recibida (neutro), En análisis (`pendiente-soft`), En revisión (`alerta-soft`), Liberada (`conforme-soft`), Rechazada (`fuera-soft`). En captura (`pera-soft`) marca la muestra en la que se trabaja ahora: solo una a la vez.
- Nunca solo color: icono y palabra siempre.
- Los nombres son una propuesta; deben coincidir con los estados del flujo real del laboratorio.
- El consumidor provee: el estado y, si aplica, quién y cuándo lo cambió (en `caption`).
