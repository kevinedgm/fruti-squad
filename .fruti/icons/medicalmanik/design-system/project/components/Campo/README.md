# Campo

Campo de captura. Atkinson en todo el texto: distingue 1, l e I, y 0 y O.

- 44 px, borde «line-control», radio `radius-md`, etiqueta `label` arriba y ayuda `caption` abajo.
- Campos numéricos clínicos (dosis, peso, glucosa): cifras tabulares, alineados a la derecha, unidad fija como sufijo en «muted». La unidad la pone el sistema, no la persona.
- Error: borde de 2 px en «error», icono y mensaje que dice el límite («máximo 100 mg al día»). Nunca solo color.
- El consumidor provee: etiqueta, unidad, rango válido y mensaje, `id` y `aria-describedby`.
