# Estado

Estado: icono + texto sobre el fondo suave del estado, iguales en todas las apps.

- Éxito, aviso, error e información; texto `on-<estado>-soft` (≥4.5:1).
- Nunca solo color: los colores de producto se parecen a los de estado (Farmacia/éxito, Compras/aviso, Grupos/error); el icono y la palabra los separan.
- Las alergias van siempre como error, en la cabecera del paciente.
- El consumidor provee: el estado y el texto exacto.
