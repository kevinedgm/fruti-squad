# SelloProducto

Sello de cada producto: la misma línea de pulso en un contenedor que cuenta qué es la app.

- La línea es idéntica en todos; el rasgo vive en el borde y nunca la corta: carpeta (Expediente), argollas (Agenda), ticket (Compras), cruz (Farmacia), flecha (Impulsa), tarjeta detrás (Grupos).
- Nombre: el producto en Sora 600 (`app-name`) y «Manik» en 400 y «muted». Nunca «Manik Farmacia» ni solo «Farmacia» como marca.
- Color: `app-<producto>` es identidad, no interfaz (ver README, Color).
- Tamaño mínimo 24 px; a 16 px solo en pestañas del navegador.
- El consumidor provee: el producto y el tamaño. Archivos en el grupo de assets «Sellos».
