# Boton

Botón: la acción principal es azul Manik en TODAS las apps, sin importar el color del producto.

- `primario`: «manik» con «on-manik»; una por vista. `secundario`: «surface», borde «line-control», texto «manik». `terciario`: solo texto. `destructivo`: borde y texto «error», siempre con confirmación.
- 44 px (`control-height`), radio `radius-md`, texto `button` (Atkinson 600). Foco: anillo «focus» 2 px.
- Por qué no el color del producto: los colores de Farmacia, Compras y Grupos coinciden con éxito, aviso y error; un botón verde o rojo diría otra cosa. El mismo botón en todas las apps también evita reaprender al cambiar de app.
- El consumidor provee: verbo + objeto, estado de carga y `aria-disabled`.
