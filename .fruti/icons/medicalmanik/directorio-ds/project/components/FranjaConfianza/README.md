# FranjaConfianza

El único plano oscuro del directorio: tres razones para confiar, dichas como hechos.

- Fondo `tinta`; títulos en blanco (Urbanist 600); texto en `confianza-texto`; iconos en `confianza-icono` dentro de un cuadro translúcido.
- Cada razón es verificable: verificación de cédula, opiniones solo de citas agendadas, sin costo para el paciente. Nunca promesas que no se pueden medir («¡Los mejores doctores!»).
- Tres columnas en escritorio, una en celular.
- El consumidor provee: las tres razones y sus iconos.
