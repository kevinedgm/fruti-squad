# Horarios

Horarios disponibles como botones en píldora: tocar uno lo elige; «Agendar» confirma.

- Contorno y texto `cian-ui`; elegido: fondo `cian-ui`, texto blanco. `aria-pressed` dice cuál está elegido.
- Cifras tabulares (`horario`) para que las horas se alineen; formato 24 h sin ceros a la izquierda (9:30).
- Arriba, el día en palabras («Hoy», «Mañana», «Lunes 3») y una ayuda en «muted».
- 42 px de alto: holgado para el dedo. Máximo una fila en la ficha; «Ver más horarios» lleva al perfil.
- El consumidor provee: fecha, horarios y el elegido.
