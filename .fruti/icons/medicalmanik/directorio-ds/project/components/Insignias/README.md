# Insignias

Chips de datos dentro de la ficha. Cada uno es un dato, no una acción.

- **Calificación:** estrella `estrella` (solo gráfico, 2.2:1) y el número escrito en tinta: «4.9 · 312 opiniones».
- **Distancia:** icono map-pin y «1.8 km».
- **Cédula verificada:** `exito` sobre `exito-suave`, icono badge-check. Solo cuando Manik revisó la cédula.
- **Nuevo en Manik:** `luz-calida`, en lugar de la calificación mientras no hay opiniones.
- Fondo `bruma` para los neutros; 14 px (`dato`).
- El consumidor provee: calificación y número de opiniones, distancia, verificación.
