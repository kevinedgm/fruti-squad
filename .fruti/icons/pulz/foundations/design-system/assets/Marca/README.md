La Z del trasiego: dos barras son tanques y la diagonal es el movimiento del lote entre ellos. Las barras van en `ink` (por `currentColor`) y la diagonal y el lote en `anil` (`--pulz-color`). Como `<img>` no heredan el color: usa el archivo `-oscuro` sobre fondos oscuros, o incrusta el SVG en línea. `simbolo-16` es la versión sin lote para 16–20 px. `favicon` cambia solo al tema oscuro. `app-icon-redondeado` es el icono de la PWA. `firma` es «hecho con PULZ» para los portales de cada palenque; su diagonal toma el color de la empresa con `--pulz-color` si pasa 3:1. Tamaño mínimo del símbolo: 24 px; del wordmark: 72 px de ancho; margen libre: el alto de una barra.
