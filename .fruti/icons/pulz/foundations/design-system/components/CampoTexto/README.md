Campo de texto o número con etiqueta visible encima. El consumidor da la etiqueta, el valor, `inputmode` (decimal para mediciones) y, si hay error, el mensaje. Borde `control` (3:1); al enfocar, borde `anil` y anillo `focus`. Las cifras usan `tabular-nums` y la familia `ui`, cuyo cero lleva raya. El error va en `grana` con texto que dice qué falta y qué hacer, nunca solo el borde rojo. Alto `size-control` con el dedo y `size-control-fine` con ratón; radio ¼ del alto. Nunca etiqueta solo como placeholder.
