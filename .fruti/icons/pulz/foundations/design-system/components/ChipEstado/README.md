Etiqueta de estado de un lote, una tina o una medición. El consumidor da el texto y el tipo: en proceso (`anil` sobre `anil-soft`), listo (`verde`), revisar (`cempasuchil`), falta o error (`grana`). Siempre lleva palabra: el punto de color es refuerzo, no el mensaje; en escala de grises se sigue leyendo. Alto `size-tag` 32 con el dedo y 28 con ratón, radio `radius-tag`. Con `forced-colors` conserva un borde. Al cambiar de etapa, el chip anterior se vacía hacia la derecha y el nuevo se llena desde la izquierda (Movimiento).
